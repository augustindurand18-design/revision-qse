Les documents traitent de : 
 
  
Aucune procédure, ni manuel n’est obligatoire. 
 
Unique notion d’informations documentées, qui peuvent se rapporter : 
 Aux informations créées en vue du fonctionnement de l’organisme  documents qui servent de 
supports : manuel, fiche processus, procédure, instruction, mode opératoire, consigne, plan, …  
 Aux preuves des résultats obtenus  enregistrements qui prouvent la réalisation ou l’efficacité : 
enregistrements de contrôle, CR de réunions, rapports d’audits, BL fournisseur signé, fiche 
d’émargement, … 
 
« Informations documentées » = « Information devant être maîtrisée et tenue à jour ainsi que le support sur 
lequel elle figure » 
 
Finalités :  
 Homogénéiser les pratiques 
 Démontrer la conformité des produits/services 
 Prévenir les pertes de connaissances 
 Améliorer l’intégration des collaborateurs 
 
Doivent être appropriés : 
 Leur identification : titre, date, auteur, référence unique, numéro de version … 
 Leur format : papier / informatique, langue, version logicielle, texte limité … 
 Leur revue : périodique 
 
Définition d’une procédure : 
 Le fond :  
o Liste étape par étape, les différentes tâches à effectuer pour achever une action  
o Répond au QQOQC : quoi, qui, où, quand, comment 
o Peut servir de support de formation 
 La forme :  
o Renforce la compréhension du fond et donc la mise en application 
o Est choisie par l’entrepris

PARTIE 2 – LA GESTION DOCUMENTAIRE 
 
La gestion des documents vise à assurer que les informations documentées : 
 
 Sont disponibles et adaptées, quand et où nécessaire : 
o Pas de document perdu ou indisponible 
o Accès assuré aux documents nécessaires 
o Pas de document incompréhensible pour l’utilisateur 
o Pas d’ancienne version disponible 
o Enregistrements disponibles 
o … 
 
 Sont convenablement protégées : 
o Pas de documents abimés, effacés, illisibles 
o Pas de documents détruits par erreur 
o …  
 
La maîtrise des informations documentées passe par :

 Distribution, accès, récupération : 
o Définir qui rédige, approuve et/ou diffuse les documents 
o Assurer l’accès à tous les utilisateurs concernés (physique ou informatique) 
o Définir un emplacement d’accès clair et le respecter 
o Assurer qu’une seule version est utilisée (pas de vieilles copies sur les postes) 
o Définir clairement les canaux de transmission des documents (quand, où) 
o Informer les salariés des canaux définis 
 
 Stockage et protection : 
o Définir les conditions dans lesquelles conserver les documents, en attente d’utilisation ultérieure 
o Assurer que les conditions nécessaires sont respectées 
o Identifier chaque support d’information 
o Définir qui est responsable de cette identification 
o Définir les autorisations (consultation, modification, destruction) 
o Informer les salariés de ces autorisations 
o Protéger les informations documentées conservées comme preuves de conformité contre toute 
altération involontaire 
 
 Maîtrise des modifications : 
o Définir les autorisations de modification des documents 
o Modifier les documents uniquement en cas de vrai besoin 
o Expliquer les modifications aux acteurs concernés 
o Ne jamais modifier un document sans mettre à jour son numéro de version 
 
 Conservation et élimination : 
o Définir où/comment doit être conservé chaque document 
o Définir la durée de conservation avant destruction 
o Assurer les conditions nécessaires à cette conservation (absence d’humidité et de poussières 
excessives, boites/cartons d’archivage…) 
o Durées d’archivage : 
 Réglementaire 10 ans pour les éléments comptables et pièces justificatives 
 Réglementaire 5 ans pour les documents de transports 
 Réglementaire 3 ans pour les éléments douaniers  
 Conseillée 3 ans pour les documents liées au SMI 
o Définir qui peut détruire des documents 
o Définir comment détruire chaque document (documents avec données confidentielles) 
 
Cas des documents externes : 
 
Ils doivent être maîtrisés/protégés de la même manière. 
 
Exemples : 
 Normes produits 
 Demande de devis, bons de commandes, contrats clients 
 Certificats, attestations, docs techniques de fournisseurs 
 Bons de livraison, factures fournisseurs 
 Documents réglementaires (Conventions collectives…) 
 …

PARTIE 3 – LES DOCUMENTS OPERATIONNELS 
 
Finalités : 
 
Les documents opérationnels permettent : 
 S’assurer le respect de critères qualité 
 De protéger l’environnement 
 D’assurer la santé et sécurité des salariés 
 De respecter un calendrier 
 De prévenir des défaillances 
 De former facilement les salariés 
 
Pour augmenter :  
  
Exemples de documents opérationnels : 
 
  
Contenu : 
 Quoi : Actions 
 Qui : Acteurs 
 Ressources : Entrants 
 Quand : Timing/délai à respecter 
 Comment : Eléments à respecter 
 Pourquoi : résultats à atteindre 
 
Qualités essentielles : 
 Clairs 
 Faciles à comprendre (visuel, vocabulaire) 
 Adaptés au public 
 Agréables à utiliser 
 Niveau d’information juste nécessaire 
 Enregistrement adapté à l’utilisation 
 …
